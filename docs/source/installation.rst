Installation
============
 
FoldKit can be installed from PyPI.
 
Installing from PyPI
---------------------
 
.. code-block:: bash
 
    pip install foldkit
 
Once installed, verify it by importing FoldKit in Python:
 
.. code-block:: python
 
    >>> import foldkit
    >>> foldkit.__version__
    '0.1.3'
 
Upgrading
---------
 
.. code-block:: bash
 
    pip install --upgrade foldkit
